# Cube Draft

Magic-Cubes offline auf dem iPhone gegen Bots draften. Die Bots sind dieselben wie im Cube-Generator am PC
(die App rechnet mit dessen `draft.py`, im Browser per Pyodide). Drafts gehen als Datei zurück an den PC.

Einrichten: Die Seite in Safari öffnen, Teilen › „Zum Home-Bildschirm“, ab dann über das Symbol öffnen.
